# HMS Marketing Studio

Sanity Studio for marketing content only. HMS remains the source of truth for rooms, pricing, availability, admissions, reservations, tenants, and payments.

## Required environment

```bash
SANITY_STUDIO_PROJECT_ID=your_project_id
SANITY_STUDIO_DATASET=production
```

The Studio also accepts `SANITY_PROJECT_ID` / `SANITY_DATASET` aliases, but the `SANITY_STUDIO_*` names are preferred.
After changing `.env`, stop and restart `npm run dev` so the Studio reloads the project configuration cleanly.

The Vite frontend reads the same project through:

```bash
VITE_SANITY_PROJECT_ID=your_project_id
VITE_SANITY_DATASET=production
VITE_SANITY_API_VERSION=2026-06-01
```

## Commands

```bash
cd sanity
npm install
npm run dev
npm run build
```

Open the customized Studio at `http://localhost:3333`. The nested `sanity/sri-adithya-hostels/` folder was generated by the Sanity CLI bootstrap; the HMS marketing schemas live in this `sanity/` workspace.

Use `npm run dev` for local editing. It binds to `localhost`, which avoids Sanity CORS errors from opening the Studio at `0.0.0.0`.
Use `npm run dev:lan` only when another device needs to reach the Studio, and add that exact LAN origin in Sanity project CORS settings first.
